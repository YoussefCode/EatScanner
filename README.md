# EatScanner Workspace

Deze workspace bevat nu alleen de React Native (Expo + TypeScript) app:

- [EatScannerReactNative](EatScannerReactNative)

## Starten

1. Open een terminal in [EatScannerReactNative](EatScannerReactNative)
2. Installeer dependencies met `npm install`
3. Start development met `npm run start`

## Testen

- `npm test`
- `npx tsc --noEmit`

Volledige projectdocumentatie staat in [EatScannerReactNative/README.md](EatScannerReactNative/README.md).
